# Caprichos de Lili — Landing Page

Sitio web oficial de **[Caprichos de Lili](https://caprichosdelili.com)**, comida sin gluten artesanal en Asunción, Paraguay.

Hecho por la **Dra. Norma Liliana Borja** (médica neonatóloga celíaca) y **Roberto Rodas**.

## Stack

- HTML estático + Tailwind CDN + JS vanilla (sin build step)
- Hosting: Cloudflare Pages
- Deploy: automático en cada push a `main`

## Páginas indexables

- `/` — Home
- `/pack-semanal/` — Menú completo
- `/pan-sin-gluten/` — Pan sin gluten Asunción
- `/comida-sin-gluten-asuncion/` — Comida sin gluten hub
- `/recetas-sin-gluten/` — Recetas con Recipe Schema
- `/celiacos-asuncion/` — Guía celiaquía
- `/contacto/` — Formulario WhatsApp
- `/libro-recetas-sin-gluten/` — Libro Amazon Kindle
- `/blog/` — Hub blog + 8 posts
